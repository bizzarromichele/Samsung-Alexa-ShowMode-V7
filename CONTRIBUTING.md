# Contribuire

Grazie per aiutare a rendere questa guida riproducibile.

1. Apri una Issue usando i modelli **Bug report** o **Device report**.
2. Per modifiche alla documentazione crea un fork e invia una Pull Request con descrizione e test eseguiti.
3. Specifica modello Samsung, versione Android, versione APK, passaggi e risultato.
4. Distingui sempre fatti osservati, ipotesi e soluzioni confermate.
5. Oscura seriali ADB, DSN, email, token, cookie, log di autenticazione e identificativi personali.
6. Non caricare APK Amazon, firmware proprietari o dati provenienti da dispositivi altrui.
7. Non proporre bypass di autenticazione, impersonificazione o copia di identificativi tra dispositivi.

Le PR sono aperte a tutti. L'accesso diretto alla repository richiede un invito del maintainer.
